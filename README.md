# WorkBalance

**Repository documentation status: under review.**

This is a separate Laravel application, **not the FLUXA admin-panel project**. The old README was copied from FLUXA and incorrectly described this repository; it has been replaced to avoid misrepresenting the source.

## What is visible in the code

The repository contains Laravel / Livewire modules and application code for:

- Request-for-quotation (RFQ) and supplier/quote workflows
- Role and permission middleware
- Workflow notifications, events and deadline handling
- HumanOps dashboards, reporting and monitoring modules

These are **source-level observations**, not a claim that all features are tested or production-ready.
